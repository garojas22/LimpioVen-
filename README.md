# 🧽 LimpioVen

Landing page corporativa para LimpioVen, C.A., empresa venezolana de limpieza y mantenimiento industrial. El proyecto está pensado para convertir visitas en clientes: la mayoría de los visitantes llega desde el teléfono y el contacto se hace directamente por WhatsApp.

## 🛠️ Tecnologías Utilizadas

* **Frontend:** React, Vite y Tailwind CSS.
* **Formularios:** Web3Forms, sin backend propio.
* **Despliegue:** Vercel.
* **Control de Versiones:** Git y GitHub.

## 🚀 Características Principales

* **Móvil primero:** Diseño optimizado para teléfonos y conexiones lentas, adaptado también a escritorio.
* **Contacto por WhatsApp:** El formulario registra la solicitud por correo y abre WhatsApp con un mensaje ya redactado con los datos del visitante.
* **Modo claro y oscuro:** La página se adapta automáticamente a la configuración del dispositivo.
* **SEO y rendimiento:** Etiquetas semánticas, metadatos y vista previa optimizada al compartir el enlace.
